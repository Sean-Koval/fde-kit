# Operating principles

These principles guide effective FDE work across every customer engagement.

## Start with the work, not the solution

Observe the customer’s current workflow, decisions, constraints, and incentives before advocating an approach. A technically elegant answer to the wrong problem is still the wrong answer.

## Make evidence visible

Separate observations, assumptions, decisions, and open questions. Bring the relevant people into that shared view so the team can challenge weak assumptions early and make progress for clear reasons.

## Deliver value in small, testable increments

Choose the smallest useful step that can validate a meaningful assumption or improve a real workflow. Use each result to decide whether to deepen, change, or stop the investment.

## Build for adoption and ownership

Treat enablement, operating readiness, and handoff as part of the solution. The customer should understand the outcome, know who owns it, and be able to use and evolve it without continuous FDE dependence.

## Communicate with precision

Adapt the level of detail to the audience while keeping the underlying facts consistent. State trade-offs, decisions, risks, and next steps plainly; ambiguity is costly in cross-functional delivery.

## Create reusable leverage

Capture lessons only when they can improve future work. Put concepts in learning, cross-stage techniques in skills, directly usable artifacts in the toolkit, and completed narratives in examples.

## Use the lifecycle as a learning loop

The [engagement lifecycle](engagement-lifecycle.md) provides a shared language for sequencing work. Revisit earlier stages when new evidence changes the problem frame, solution approach, or readiness to proceed.
