# Learning center

Learning explains the concepts and mental models behind effective Forward Deployed Engineering. It answers **what** an FDE should understand and **why** it matters; it does not contain reusable templates or detailed instructions for a particular stage.

Start with these foundations:

- [What is an FDE?](what-is-an-fde.md) defines the role and its measures of success.
- [Operating principles](operating-principles.md) describes the habits that make engagement work effective.
- [Engagement lifecycle](engagement-lifecycle.md) explains the shared progression from discovery through expansion.
- [FDE overview presentation](presentations/fde-overview.html) provides a high-level visual introduction.

When you need to decide what to do in an active engagement, use the lifecycle as orientation and then consult the relevant stage guidance as it becomes available.
