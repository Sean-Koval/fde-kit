# Learning center

Learning explains the concepts and mental models behind effective Forward Deployed Engineering for AI implementation. This repository focuses on how an AI FDE turns operational problems into adopted, governed production systems; it does not attempt to describe every form of forward-deployed work. Learning answers **what** an AI FDE should understand and **why** it matters; it does not contain reusable templates or detailed instructions for a particular stage.

## Foundations

- [What is an FDE?](what-is-an-fde.md) defines the role, its measures of success, and the operating model.
- [Operating principles](operating-principles.md) describes the habits that make engagement work effective.
- [Engagement lifecycle](engagement-lifecycle.md) explains the shared progression from discovery through expansion and when to loop back.
- [AI system patterns](system-patterns.md) shows the five boundary-and-control shapes for placing a model in a workflow, with diagrams.
- [AI Implementation Field Playbook](presentations/fde-overview.html) is a field-focused visual introduction. GitHub displays it as HTML source: clone or download the repository, then open `learning/presentations/fde-overview.html` in a browser.

## Becoming an AI FDE

- The [curriculum](curriculum/README.md) sequences the whole kit into seven modules, each producing an artifact, ending in a capstone engagement with a rubric.
- [Preparing for AI FDE interviews](interview-preparation.md) describes the interview shapes these roles use and drills that reuse the curriculum exercises.
- The [glossary](glossary.md) defines the terms the kit uses in its own sense.

## Using this section

When you need to decide what to do in an active engagement, use the lifecycle as orientation and then consult the relevant [stage guidance](../stages/README.md). The [skills](../skills/README.md) teach the methods, the [toolkit](../toolkit/README.md) provides copy-ready artifacts, the [examples](../examples/README.md) show a completed engagement, and the [agent skills](../agents/README.md) run the same methods inside an agent harness.
