# Learning center

Learning explains the concepts and mental models behind effective Forward Deployed Engineering for AI implementation. This repository focuses on how an AI FDE turns operational problems into adopted, governed production systems; it does not attempt to describe every form of forward-deployed work. Learning answers **what** an AI FDE should understand and **why** it matters; it does not contain reusable templates or detailed instructions for a particular stage.

Start with these foundations:

- [What is an FDE?](what-is-an-fde.md) defines the role and its measures of success.
- [Operating principles](operating-principles.md) describes the habits that make engagement work effective.
- [Engagement lifecycle](engagement-lifecycle.md) explains the shared progression from discovery through expansion.
- [AI Implementation Field Playbook](presentations/fde-overview.html) provides a field-focused visual introduction to AI implementation work.

GitHub displays the playbook as HTML source. Clone or download this repository, then open `learning/presentations/fde-overview.html` in a browser.

When you need to decide what to do in an active engagement, use the lifecycle as orientation and then consult the relevant [stage guidance](../stages/README.md). The [skills](../skills/README.md), [toolkit](../toolkit/README.md), and [examples](../examples/README.md) sections currently define curated catalogs and contribution contracts; substantive guides, reusable artifacts, and worked engagements will be added only when they meet the repository quality bar.
